TaskGen templates by difficulty

Last updated: 2026-10-29 00:53 IST (TaskGen; clock time). Started at the user's request (2026-10-29: "lets start a doc with templates as well, to showcase difficulty wise as well"). A showcase of the task templates, from easiest to hardest, on res31's build_v1 scenes. Design and rules: TASKGEN_DESIGN.html. Draft: the levels and the difficulty scores are TaskGen's proposal, not measured. Variant counts are computed from each scene's objects; nothing here has been run on these scenes yet. Every number from new code is UNVERIFIED.

How to read it. A template is a task with placeholders (slots). Its variants are the slots' permutations and combinations, filled from each scene's own objects, so one template runs on every scene. Each template lists what makes it hard (the axes in §1), its pass condition, the expert that proves it solvable, and its state. Renders per template go in the last column once the presets have been run on the scenes.

4 · How a template is written (example: L5 T-stack)

template: ordered_stack
  slots:
    order : permutation of {blocks in this scene}             task slot
  instruction:    "stack the blocks: {order[0]} at the bottom, then {order[1]}, then {order[2]} on top"
  pass_all:       [ordered_stack(order)]
  expert:         derived from pass_all: pick order[1] → onto order[0]; pick order[2] → onto order[1]
  count:          3! = 6 on orange; 2! = 2 on c11 and c1b
