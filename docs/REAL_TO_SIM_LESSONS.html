Real-to-sim scene building: failures seen and how they were fixed

Internal handover, written 10-15 by res31 from the 10-14 → 10-15 work. Code: experiments/real2sim/. Context: docs/REAL_TO_SIM_SCENES.html (survey + §10 log). Videos: runs/real2sim/videos.html, runs/real2sim/tasks/presentation.html. All numbers are exploratory and not val-checked.

If you only read one thing: nothing in this pipeline can be trusted until it has been checked against something independent. Every serious bug below was caught by one of four checks:
  1. overlay the sim robot (or recorded gripper path) on the real frames;
  2. compare fitted object positions/heights with where the recorded gripper actually closed;
  3. run physics for 0.5 s and see whether anything moves or falls;
  4. look at the rendered frames yourself.
Do these after every change. Don't guess conventions, offsets or units: test them with a projection or a sim check first.

6 · Process mistakes (mine)

  • Guessing. I stated "is MuJoCo inferior?" from memory, assumed a 0° gripper mount, assumed DROID's camera was right, and announced a bowl bug that wasn't one. The user's rule: check first, then state or use.
  • pkill -f <pattern> matched its own shell and killed the command. Use the PID.
  • grep in a pipe buffers output until exit; use --line-buffered for live logs.
  • Two jobs writing the same output path overwrote each other (Telea vs LaMa composite). Give each run its own name.
  • The user's rule: commit before new work. prim does all commits; send a commit request and verify the hash in git log before continuing.

8 · Checklist for a new scene

  1. Pick an episode with a fixed camera, the robot well in view, and recorded joint angles; get the lens values from the dataset if they exist.
  2. perceive.py with generic category prompts; look at perception_check.png.
  3. build_scene.py --scale raw, then calibrate_cam.py (motion masks, global search, --level_weight 1); look at the overlay (target IoU ≥ 0.4).
  4. build_scene.py --calib ... --anchor_frame <a frame where the robot is clearly visible>; check scene_fit.json sizes and the settle movement (< 2 cm).
  5. wrist_anchors.py (wrist-stereo object points), then calibrate_cam.py --init ... --anchors ... --table_z ..., then build_scene.py --calib ... --depth stereo.
  6. scene_checks.py: settle, real grasp/release, scale, stereo table; look at wrist_overlay.jpg. Don't use the scene until it passes (see REAL_TO_SIM_PREDEPLOY_CHECKLIST.html).
  7. scripted_grasp.py / make_tasks.py; then composite.py --inpaint lama --holes frame0+plate; look at frames.
