Reference

Every number in the R-039 and R-041 results, written out

Companion to the pipeline spec (glossary at its end) and the R-039 results. Symbols: h is the action head run to completion (four Euler steps); p and n are the perturbed and nominal input sets; ε is the denoising noise.

One forward emits a chunk of 40 actions; the LIBERO arm uses the first 7 of the 132 output dimensions. Flatten the live chunk to a vector a ∈ ℝ280. Distances are Euclidean on that vector.

The five arms at forward f
From one simulator state and one fixed noise draw εf, the head is run with inputs (xT, xI, xS) chosen from the perturbed run p or the nominal source n: aP = h(pT, pI, pS; ε)   aN = h(nT, nI, nS; ε)   aI = h(pT, nI, pS; ε)   and likewise aT, aS This is an interchange intervention (Geiger et al. 2021) on one input at a time; in the activation-patching vocabulary it is denoising: a clean activation is patched into the corrupted run (Heimersheim & Nanda 2024, arXiv:2404.15255; Meng et al. 2022, arXiv:2202.05262, "causal tracing"). Fixing ε across the five arms is common random numbers, the standard variance-reduction device for comparing alternatives under one noise stream.
Effect size
‖P−N‖ = ‖aP − aN‖2 How much the perturbation moved the action at that forward. Zero means the perturbation has not reached the action yet.
Transfer fraction
τX(f) = 1 − ‖aX − aN‖ / ‖aP − aN‖,   X ∈ {T, I, S} The share of the perturbed-to-nominal gap that restoring input X alone closes. τ = 1: that input carried everything. τ = 0: it carried nothing. τ < 0: restoring it moved the action further away. τ ≤ 1 always. This is the normalised patching metric of Heimersheim & Nanda (2024) and Zhang & Nanda (ICLR 2024, arXiv:2309.16042), (patched − corrupted)/(clean − corrupted), with the scalar logit replaced by distance to the clean action, which is the natural choice when the output is a vector rather than a logit. Grant, Zhao & Wang (arXiv:2603.19233) report action cosine similarity instead; cosine ignores magnitude, which for a 7-dof delta action is most of the information, so distance was chosen and pre-registered. τT + τI + τS need not equal 1: single-input patches measure each pathway with the others held perturbed, and interactions are not additive (the order-dependence result in TRIGGER_MECHANISM_CALCULUS.html; Shapley 1953 is the additive repair, not applied here). The sum is reported only as an exploratory check.
Onset, anchor, dominant arm, residual
onsetX = min{ f : τX(f) ≥ 0.5 } f* = the forward whose 16-step window contains argmint ‖eeft − bowlt‖   (the anchor; R-038's discriminator) dominant = argmaxX τX(f*) if that maximum ≥ 0.9, else none (residual) The anchor is the forward containing the closest approach to the target bowl, found from the privileged simulator distance in the trace and mapped to a forward by the logged env step of each forward, never by assuming 16 steps per forward.
Drift and aggregation
S-slope = least-squares slope of τS(f) against f Positive slope would mean the state pathway takes over as the episode drifts. Per category, every statistic is the median over its ten instances; "n positive" counts instances with slope above 0.05.
The state-token control (R-039 expectation 1)
r0 = ‖aP − h(pT, pI, 0; ε)‖ / ‖P−N‖,   rctl = ‖aP − h(pT, pI, nS; ε)‖ / ‖P−N‖ If deleting the state token (r0) moves the action about as little as swapping it (rctl), the token is low-influence and the S splice is not at fault. Measured: r0 = 0.10, rctl = 0.17, against 0.91 for the image swap.
R-041's action boundary
τact = 95th percentile of ‖aP(f+1) − aP(f)‖ over all magnitude-0 rollouts action boundary = min{ m : ‖P−N‖(f=0; m) > τact }, found by bisection The threshold is the policy's own forward-to-forward variation under no perturbation, computed before any perturbed rollout is analysed.

Sources

Where each piece comes from

  • Interchange interventions. Geiger, Lu, Icard, Potts. Causal Abstractions of Neural Networks. NeurIPS 2021. Replacing one component's value with its value under another input and reading the output.
  • Causal tracing / denoising. Meng, Bau, Andonian, Belinkov. Locating and Editing Factual Associations in GPT. NeurIPS 2022, arXiv:2202.05262. Clean activations restored into a corrupted run; the recovered fraction locates the mechanism.
  • The normalised metric and its pitfalls. Heimersheim, Nanda. How to use and interpret activation patching. arXiv:2404.15255 (2024). Zhang, Nanda. Towards Best Practices of Activation Patching in Language Models: Metrics and Methods. ICLR 2024, arXiv:2309.16042. Define (patched − corrupted)/(clean − corrupted), the denoising-versus-noising distinction, and why single-component patches are not additive.
  • Path patching. Wang, Variengien, Conmy, Shlegeris, Steinhardt. Interpretability in the Wild: a Circuit for Indirect Object Identification in GPT-2 small. ICLR 2023. Patching along one path while holding the others; the model for "one input restored, others held perturbed".
  • Mediation. Vig et al. Investigating Gender Bias in Language Models Using Causal Mediation Analysis. NeurIPS 2020; Pearl. Direct and Indirect Effects. UAI 2001. The transfer fraction estimates the share of the total effect mediated by one pathway; the non-additivity is the interaction term in Pearl's decomposition.
  • Order dependence. docs/TRIGGER_MECHANISM_CALCULUS.html, the AND-gate example; Shapley. A Value for n-Person Games. 1953, the additive attribution obtained by averaging over orders, not applied here.
  • Activation injection on VLAs. Grant, Zhao, Wang. Not All Features Are Created Equal: A Mechanistic Study of Vision-Language-Action Models. arXiv:2603.19233 (2026). Same intervention on GR00T N1.5 with action cosine similarity as the metric.
  • Common random numbers. Standard variance reduction for comparing alternatives under one noise stream; e.g. Glasserman, Yao. Some Guidelines and Guarantees for Common Random Numbers. Management Science 1992.
